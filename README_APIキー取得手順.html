APIキーの取り方（不動産情報ライブラリ）

このシステムで本物のデータを使うには、国土交通省の「不動産情報ライブラリ」から 無料のAPIキー（合言葉のような文字列）を1回だけ取得します。取得まで数日かかる場合があります。 それまではデモモードでお試しいただけます。

ステップ1：申請ページを開く

下のボタンを押すと、申請ページがブラウザで開きます。

▶ 不動産情報ライブラリ APIマニュアル・申請ページを開く

ページ内の「API利用申請」または「利用申請フォーム」へ進みます。

▶ 直接 申請フォームを開く

ステップ2：申請フォームに入力

  1. お名前・メールアドレス・利用目的などを入力します。 利用目的は「不動産の簡易な時価評価のため」などで問題ありません。
  2. 利用規約に同意して送信します。
審査後、登録したメールアドレス宛にAPIキーが届きます （すぐに届かず、数日かかることがあります）。

ステップ3：届いたキーをシステムに登録

  1. メールに書かれた Ocp-Apim-Subscription-Key（英数字の長い文字列）をコピーします。
  2. 「起動.command」でシステムを開き、画面左の「デモモード」をOFFにします。
  3. 左側の「APIキー」欄にキームを貼り付けて、「保存」ボタンを押します。
  4. これで本物のデータが使えるようになります。キーの登録は最初の1回だけです。

困ったとき

  • キーを間違えると「認証エラー」と表示されます。もう一度コピーし直してください。
  • キーを取り直したいときは、APIキー欄の「消去」を押してから登録し直します。
