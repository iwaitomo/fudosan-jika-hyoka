🏠 このアプリを公開して、スタッフや仲間だけに使ってもらう手順

ネット上に公開しつつ、「合言葉」を知っている人だけが使えるようにします。 合言葉は人ごとに配れ、辞めた人の分だけ後で無効化できます。

⚠️ 依頼者情報の守秘についての大事な注意
公開すると、アプリは外部サーバ（Streamlit の無料クラウド）で動きます。
そのため公開版では「案件の保存・読込」を既定で無効にしています （依頼者情報を外部に置かないため）。時価の試算だけに使ってください。
案件として保存したいときは、事務所PCのローカル版（起動.command）をお使いください。

STEP 1　GitHub の無料アカウントを作る

  1. https://github.com/signup を開き、メールアドレスで無料登録します。
  2. あわせて「GitHub Desktop」（無料アプリ）を入れると、ファイルのアップロードがクリック操作でできて簡単です： https://desktop.github.com/

STEP 2　このアプリ一式を GitHub に置く

  1. GitHub Desktop を開き、「File → Add Local Repository」でこのフォルダ （不動産時価評価システム）を選びます。 「create a repository」を促されたら、そのまま作成してください。
  2. Publish repository を押してアップロード。公開範囲は Private（非公開）を選ぶと安心です。
秘密情報は自動で除外されます。 .gitignore により、APIキー（apikey.txt）・案件データ（data/）・ 合言葉（secrets.toml）はアップロードされません。安心してそのまま進めてください。

STEP 3　Streamlit の無料クラウドでアプリを起動する

  1. https://share.streamlit.io/ を開き、 「Continue with GitHub」で先ほどのアカウントで入ります。
  2. Create app → Deploy a public app from GitHub を選びます。
  3. Repository＝先ほどのリポジトリ、Branch＝main、 Main file path＝app.py を指定して Deploy。
  4. 数分でビルドされ、https://〇〇〇.streamlit.app のURLが発行されます。

STEP 4　合言葉とAPIキーを設定する（ここが本体）

  1. アプリ画面の右下メニュー Manage app → ⋮ → Settings → Secrets を開きます。
  2. 同じフォルダにある secrets.toml.example をテキストで開き、 中身をまるごとコピーして Secrets 欄に貼り付けます。
  3. 次の3か所を実際の値に書き換えて Save：
    • REINFOLIB_API_KEY … 国交省APIキー（全員で共有。各自取得は不要）
    • [access] の各行 … 「表示名 = 合言葉」を人数分。合言葉は長めに。
    • 案件保存を公開版でも使いたい場合のみ allow_case_save = true （※守秘の観点から通常は false のまま推奨）
[access]
"岩井（管理者）" = "sakura-densha-aozora-1987"
"スタッフ田中"   = "midori-kujira-tokei-4423"
"友人の佐藤"     = "hoshizora-ringo-kaze-7781"

STEP 5　みんなに配る／やめてもらう

  • 配る：発行されたURLと、その人の合言葉を伝えるだけ。開くとログイン画面が出ます。
  • 無効化する：Secrets からその人の行を消して Save。次からは入れなくなります。
  • 合言葉を変える：その行の右側を書き換えて Save。本人にだけ新しい合言葉を伝えます。
事務所PCのローカル版は、これまで通り合言葉なしで使えます。 起動.command で開いた場合は信頼環境として扱い、案件保存も使えます。

困ったとき

  • ログイン画面で「アクセス設定が未設定です」と出る → STEP 4 の Secrets 設定がまだです。
  • データが出ない → Secrets の REINFOLIB_API_KEY が正しいか確認。
  • 設定を変えたのに反映されない → Manage app から Reboot すると確実です。
